### Segundo intento de la Kata: clase User
En este intento se ha desarrollado una clase llamada user, hecha record,
en la que entran los campos email, password y username, y cuyo método aparte de los getters
es uno que verifica si la string equivalente al correo es válida como dirección de correo
mediante el uso de patrones de regex. En el Main, se han creado dos usuarios donde solo uno de ellos
tiene un correo electrónico válido, cuya prueba se muestra por terminal además de mostrar
el nombre de usuario, su contraseña y correo electrónico sea válido o no.
